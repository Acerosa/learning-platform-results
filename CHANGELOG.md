# Changelog

All notable changes are documented here. This project follows Semantic Versioning.

## 0.1.0 - 2026-08-16

### Added

- Shared educational models for evidence, results, progress, diagnostics, feedback, markbook and exports.
- Pure business-logic factories with no database or UI runtime.
- Documentation for purpose, ownership, public API and extension.
- Stored payload reconstruction, backend marking-source mapping, review-queue reasons, group summaries and automatic feedback models for the Admin Results module.
